# История изменений

## 1.0.0

Первый выпуск учебного калькулятора.

### Возможности

- Сложение двух чисел.
- Деление двух чисел с обработкой деления на ноль.
- Умножение двух чисел.

### Проверки и процесс разработки

- Восемь автоматических unit-тестов.
- Запуск тестов через GitHub Actions при отправке изменений и создании или обновлении Pull Request в main.
- Обязательное успешное прохождение тестов перед слиянием в main.
- Возможность автоматического слияния Pull Request после выполнения обязательных проверок.
