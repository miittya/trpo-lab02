# Учебный калькулятор

Проект для практической работы № 2 по CI/CD.

## Возможности

- `add(a, b)` — сложение двух чисел.
- `divide(a, b)` — деление двух чисел. При делении на ноль возникает `ValueError`.
- `multiply(a, b)` — умножение двух чисел.

## Запуск тестов

Из корня проекта выполните:

```bash
python3 -m unittest discover -v
```

В проекте используются стандартные модули Python. Установка дополнительных библиотек не требуется.

## Генерация документации

Из корня проекта выполните:

```bash
python3 -m pydoc -w calculator
```

Команда создаёт файл `calculator.html`, который можно открыть в браузере. Описания функций берутся из docstring в `calculator.py`.

## Автоматические проверки

GitHub Actions запускает тесты при отправке изменений и при создании или обновлении Pull Request в main.

После успешных тестов workflow генерирует HTML-документацию и сохраняет её в артефакте `calculator-docs`. Скачать его можно со страницы соответствующего запуска во вкладке Actions.

## Версии

Текущая версия указана в файле `VERSION`. История изменений находится в `CHANGELOG.md`.
